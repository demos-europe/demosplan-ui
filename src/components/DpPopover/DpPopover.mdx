# Popover

The Popover component renders a button that toggles a panel with additional information.

The panel is teleported to the `body` and positioned with `position: fixed` (via [FloatingUI](https://floating-ui.com/)),
so it is not clipped by scroll containers like tables with `overflow-x: auto`.
It closes on click outside and on `Escape`.

The trigger is styled with the prop `variant` (currently `outline`). Layout classes are passed with `class` and applied to the trigger button.

Use the `Flyout` component for menus with actions instead.
