# Slidebar

The `DpSlidebar` component creates a sliding side panel that can be opened and closed. It initializes a SideNav instance and provides a consistent interface for slide-in panels throughout the application.

## Features

- Right-side sliding panel
- Built-in close button
- Open/closed state controlled via the `open` prop (`v-model:open`)
- Slots for custom content
- Optional `dragHandle` slot for a resize handle
- Closes on Escape key press

## Usage

The slidebar can be used to display additional information or controls without navigating away from the current view.

## Implementation Notes

- Bind `v-model:open` (or the `open` prop plus an `@update:open` listener) to control the slidebar; it emits `update:open` and `close` on every close path (close button, Escape, swipe)
- Opening happens only through the `open` prop, not a `data-slidebar-show` attribute, because SideNav may be initialized before the corresponding DOM elements exist
- Content should be placed inside the default slot
