# TableScrollbar

The TableScrollbar component renders a custom scrollbar below a table that is wider than its container.
Unlike the native scrollbar it is always visible and sticks to the bottom of the viewport.

The component only renders track and thumb. The parent component is responsible for:

- calculating `scrollPercent` and `thumbStyle` from the scroll position of the container,
- scrolling the container when the thumb is dragged (listen to `thumbMousedown`),
- giving the scroll container an `id` and passing it as `controls`.

Set `isFullscreen` to fix the scrollbar to the bottom of the screen while the table is shown in fullscreen mode.

The example shows a parent that wires everything together: scroll the table or drag the thumb.
